## 🚀 Projetos

### 📋 DevTasks

Sistema web de gerenciamento de tarefas desenvolvido como projeto de estudo e portfólio.

**Funcionalidades:**

* Criar tarefas
* Definir prioridade
* Concluir tarefas
* Excluir tarefas
* Filtrar tarefas
* Contadores de tarefas
* Armazenamento com LocalStorage
* Interface responsiva

**Tecnologias:**

`HTML` `CSS` `JavaScript` `LocalStorage`
